# Token Efficiency

## Execution Discipline

- Prefer one well-planned tool call over multiple exploratory calls.
- Batch related edits into a single operation.
- Do not echo large files or code blocks unless explicitly requested.
- Avoid conversational filler or status confirmations.

## Context Discipline

- Avoid re-reading files you just modified unless validation is required.
- Avoid repeating commands when results are already deterministic.
- Replace long outputs with structured summaries early.

## Reporting

- Use short factual summaries instead of narrative explanations.
- Preserve only information needed for future reasoning.
